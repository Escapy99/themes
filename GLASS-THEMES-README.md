# AYN Thor Liquid Glass

Native plugin with eight theme/background modes (4 scenes × 2 translucency treatments), plus a no-image alternative. All image URLs point to the corresponding public photographs on Pexels. For an entirely offline ZIP with the actual user-supplied landscape images, use the downloadable ChatGPT file provided in the same conversation.

Install from the existing Revenge repository index at `https://raw.githubusercontent.com/Escapy99/themes/main/index.json` via Revenge → Themes → Manage theme plugins → Browse.

To change backgrounds, use Revenge → Themes → Colors → Background → Custom image, or choose another Liquid Glass theme. The image controls support opacity, blur, and dimming.

This pack affects documented theme colours. No custom React Native component blur, layout changes, or GPU-refraction effect is implemented. Some native context menus may remain opaque.
